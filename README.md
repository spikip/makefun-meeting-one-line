## About this entry

The line is a meeting in miniature, which is exactly the joke the
bounty asks for. It opens with the verdict itself, "This meeting
could have been one line: 'Do it.'", so the reader gets the point
before the punchline even arrives. Then it shows why the meeting
happened anyway: twelve people spent an hour agreeing that someone
should do it. That is office life in one sentence, a room full of
people doing the work of deciding to work, and the laugh comes from
recognising it at once. The line is a single sentence, it needs no
explanation, and it stays well inside the two hundred character cap.
The program holds the line, checks it against that cap, and writes
it to /output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
